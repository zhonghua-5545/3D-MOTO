# 3D 汽车发动机运行动画 — 设计文档

日期：2026-10-03
状态：已批准，待编写实现计划

## 1. 目标

在浏览器中呈现一台**正在运转的直列四缸汽油发动机**，通过半透明/剖切方式
露出内部结构，实时展示四冲程工作循环中活塞、连杆、曲轴、气门的运动。

受众：需要直观理解发动机内部运动的人——教学演示、作品展示。

## 2. 成功标准

1. 双击 `index.html` 即可在浏览器打开，无需构建步骤、无需 `npm install`。
2. 活塞运动**严格符合曲柄连杆机构解析解**，不是近似简谐运动。
3. 四个气缸的活塞动作**错落有致**（相位差 180° 等分），而非整齐划一。
4. 能清楚看到：活塞往复、连杆摆动、曲轴旋转、气门开合、点火时刻。
5. 可自由旋转/缩放视角，可调速、暂停、单步，可切换剖切与半透明。
6. 部件有标签，HUD 实时显示各缸所处冲程。

## 3. 非目标（YAGNI）

明确**不做**：燃烧火焰/流体特效、粒子气流、声音、配气正时链条机构、
V 型/水平对置布局、真实的凸轮轴轮廓曲线、移动端触摸优化、多页面路由。

## 4. 技术栈

| 项 | 选择 |
|---|---|
| 渲染 | Three.js（ESM，CDN + importmap） |
| 交互 | `OrbitControls`（three/addons） |
| 标签 | `CSS2DRenderer`（three/addons） |
| 构建 | 无。单文件 `<script type="module">` |
| 语言 | 原生 JS，无框架 |

**离线兜底**：`<script>` 里监听 importmap 模块加载失败（`window.addEventListener('error')`
配合模块脚本的 `onerror`），失败时在页面上显示明确提示——告知需要联网，
并给出把 `three.module.js` 下载到同目录后改用相对路径的说明。
避免用户看到一个纯黑页面而不知所以。

## 6. 坐标与单位约定

- **1 单位 = 1 cm**（建模用毫米数值除以 10，避免相机参数过大）
- **Y 轴 = 气缸轴**（活塞沿 Y 往复，向上为缸盖方向）
- **Z 轴 = 曲轴轴**（四个气缸沿 Z 排开）
- **曲轴主轴位于 y = 0**

第 i 缸（i = 0..3）的缸心 Z 坐标：`z_i = (i − 1.5) × boreSpacing`

## 7. 运动学内核（正确性命门）

曲柄半径 `r`，连杆长度 `l`，曲轴角 `θ`（弧度）。**所有角度均以「曲柄销正朝上
= 上止点」为 θ = 0 的定义**。

### 7.1 活塞销位置

```
s(θ) = r·cos θ + √(l² − r²·sin²θ)
```

活塞沿 Y 轴位于 `y = s(θ)`，X 恒为 0。

边界验证（**必须精确成立**）：
- `θ = 0°`   → `s = r + l`  （上止点 TDC）
- `θ = 180°` → `s = l − r`  （下止点 BDC）
- `θ = 360°` → `s = r + l`  （回到 TDC）

恒等式验证：对任意 θ，`r²sin²θ + (s − r·cos θ)² ≡ l²`（连杆长度不变）。

### 7.2 曲柄销位置与曲轴旋转方向

**约定**：曲柄销在曲轴局部坐标中建在 `(0, +r, ·)`——即 θ = 0 时指向 +Y
（缸盖方向，对应上止点）。曲轴 Group 的 `rotation.z = θ`（**绕 Z 轴逆时针**）。

由此推出曲柄销的世界坐标：

```
pin.x = −r·sin θ
pin.y =  r·cos θ
```

**注意 X 分量的负号**：它与 `rotation.z = θ` 是绑定的。若误写成 `+r·sin θ`，
曲轴旋转方向与连杆摆动方向将相反，连杆会朝错误一侧倾斜（活塞位置仍正确，
但连杆姿态穿模）。实现时以「θ = 90° 时曲柄销位于 −X 侧」为自检点。

### 7.3 连杆姿态

连杆几何沿 **+Y** 方向建模（小头在原点，大头在 −Y 远端，即局部轴向
大头→小头 = `(0, +1)`）。装配时把连杆放到活塞销处，然后绕 **Z 轴** 旋转：

```
rodRotationZ = atan2(r·sin θ,  √(l² − r²·sin²θ))
```

**推导**：世界坐标中小头→大头 = `(pin.x − 0, pin.y − s)` =
`(−r·sinθ, −√(l²−r²sin²θ))`，故大头→小头 = `(−r·sinθ, +√(l²−r²sin²θ))`。
将局部轴向 `(0, +1)` 绕 Z 旋转 α 得 `(−sin α, cos α)`，对应即得
`sin α = r·sinθ / l`、`cos α = √(l²−r²sin²θ) / l`，故 α 取上式。

边界验证：`θ = 0°` → 角度 = 0（连杆竖直）；`θ = 90°` → 角度 = `+asin(r/l)`
（曲柄销在 −X 侧，连杆底端偏左、顶端偏右）。

**自洽性提示**：7.1 的 `s(θ)` 只含 `cosθ` 与 `sin²θ`，因此对 X 符号不敏感；
7.3 的形状则依赖 7.2 的符号约定。改一处必须同步改另一处。

### 7.4 参数取值

真实发动机尺寸，缸径与冲程均为 86mm（方形缸）：

| 参数 | 毫米 | 单位 |
|---|---|---|
| 缸径 bore | 86 | 8.6 |
| 冲程 stroke | 86 | 8.6 |
| 曲柄半径 r = stroke/2 | 43 | 4.3 |
| 连杆长度 l | 143 | 14.3 |
| 缸心距 boreSpacing | 105 | 10.5 |
| 缸数 | 4 | — |

`r / l ≈ 0.30`，落在真实发动机典型区间 0.25–0.33 内，连杆摆动视觉效果真实。

## 8. 四冲程时序

以 **720°（曲轴两圈）** 为一个完整循环。对单个气缸，令 `θ_cycle = θ_crank + phase_i`
（对 720 取模）：

| 区间 | 冲程 | 活塞运动 | 气门 | 其他 |
|---|---|---|---|---|
| 0–180° | 进气 | TDC → BDC 下行 | 进气门开 | — |
| 180–360° | 压缩 | BDC → TDC 上行 | 全关 | — |
| 360–540° | 做功 | TDC → BDC 下行 | 全关 | θ=360° 点火 |
| 540–720° | 排气 | BDC → TDC 上行 | 排气门开 | — |

注意活塞位置公式使用的是 `θ_cycle mod 360°`——曲轴转两圈，活塞往复两次。

### 8.1 气门升程

用平滑正弦包络模拟凸轮轮廓（不做真实凸轮曲线）。设 `θ` 已对 720° 取模，
定义开启窗口内归一化进度 `u`，窗口外升程为 0：

```
intakeLift(θ):   u = ((θ − 700°) mod 720°) / 220°   → lift = (0 ≤ u ≤ 1) ? sin(π·u) : 0
exhaustLift(θ):  u = ((θ − 520°) mod 720°) / 220°   → lift = (0 ≤ u ≤ 1) ? sin(π·u) : 0
```

**相位说明**：进气门于 700° 开启（上止点前 20°）、200° 关闭（下止点后 20°），
峰值落在 90°——正是进气冲程中点。排气门于 520° 开启（下止点前 20°）、
740°（= 下个循环的 20°）关闭，峰值落在 630°——排气冲程中点。

两门开启窗口在 700°–740° 重叠 40°，形成气门重叠角。

**自检点**：进气门升程峰值必须出现在 90°（进气冲程中点），排气门峰值在 630°
（排气冲程中点）。若峰值落在 450° 附近，说明相位基准错了 360°——那正是
做功冲程，气门会全开在最不该开的时候。

升程量映射到气门沿 −Y 的位移，最大约 0.8 单位（≈8mm 真实升程）。

### 8.2 四缸相位偏移

直列四缸、点火顺序 **1-3-4-2**：

```
phase = [0°, 540°, 180°, 360°]   // 对应缸 1、2、3、4
```

由此每 **180°** 曲轴转角就有一次点火，四个活塞此起彼伏。

**验证**：排序后的相位偏移必须每 180° 等分一次，即
`sort([0,540,180,360]) = [0,180,360,540]`。

## 9. 零件清单

每个零件一个 builder 函数，返回 `THREE.Object3D`：

| 零件 | 几何构成 |
|---|---|
| 曲轴 | 沿 Z 的主轴圆柱 + 每缸 2 片曲柄臂（盒体）+ 曲柄销圆柱（偏置，平行主轴） |
| 连杆 | 沿 +Y 的杆体 + 小头环 + 大头环（用圆柱环或 Torus） |
| 活塞 | 圆柱体 + 2–3 道活塞环（薄圆柱，略大半径） |
| 活塞销 | 细圆柱，穿过活塞 |
| 缸套 | 开口圆柱，`DoubleSide`，半透明玻璃质感 |
| 缸盖 | 缸体顶部的盒体/圆柱，带气门座开孔（视觉简化） |
| 进气门 / 排气门 | 气门杆圆柱 + 气门头圆盘 |
| 火花塞 | 小圆柱 + 电极细节 |
| 飞轮 | 扁圆盘（可选加齿），装在曲轴末端 |

**曲轴的处理**：所有曲柄臂与曲柄销挂在**同一个 Group** 下，该 Group 绕 Z 轴
做 `rotation.z = θ_crank` 的旋转。这样曲轴的刚性旋转只由一个 transform 驱动，
不会出现各缸曲柄销走位不一致。

## 10. 材质与渲染

- **金属件**（曲轴、连杆、活塞销、气门）：`MeshStandardMaterial`，
  `metalness: 0.9`，`roughness: 0.25`
- **活塞**：铝合金色调，略高粗糙度（`roughness: 0.4`）以区分
- **缸套**：`MeshPhysicalMaterial`，`transparent: true`，`opacity: 0.12`，
  `DoubleSide`，`roughness: 0.1`
- **环境光照**：`RoomEnvironment` + `PMREMGenerator` 生成环境贴图，
  让金属有真实反射；配一盏定向光产生明暗对比
- **色调映射**：`ACESFilmicToneMapping`，`outputColorSpace = SRGBColorSpace`

### 10.1 剖切与半透明（两条独立路径）

1. **半透明模式** — 切换缸套/缸盖材质的 `opacity`（0.12 ↔ 0.85）与 `transparent`
2. **剖切模式** — 使用 Three.js clipping plane：
   `renderer.localClippingEnabled = true`，对缸套/缸盖材质设置
   `clippingPlanes: [plane]`，用一个沿 X 方向的平面切掉前半部分

两者由同一组 UI 按钮控制，互不冲突（可同时开启）。

### 11.1 HUD 与标签

- **HUD**：屏幕角落显示每个气缸的编号、当前冲程名（进气/压缩/做功/排气）、
  当前曲轴角。冲程用颜色区分（四色）。
- **标签**：用 `CSS2DRenderer` 把「活塞」「连杆」「曲轴」「进气门」「排气门」
  「火花塞」等文本挂在对应部件上，跟随 3D 位置移动，可整体开关。

## 12. 动画循环

```
每帧:
  dt = clock.getDelta()
  if (!paused):
      crankAngle += rpmToRadPerSec(rpm) * dt
      crankAngle %= 2π * 2          // 720° 循环
  对每个气缸 i:
      θ_i = crankAngle + phase[i]
      s   = pistonPosition(θ_i)      // 第 7.1 节
      活塞.position.y   = s
      连杆.position.y   = s
      连杆.rotation.z   = rodRotationZ(θ_i)
      进气门.position.y = −intakeLift(θ_i)
      排气门.position.y = −exhaustLift(θ_i)
  曲轴Group.rotation.z = crankAngle
  更新 HUD 文本
  controls.update()
  renderer.render()
```

所有运动学都是 `crankAngle` 的**纯函数**——没有累积状态、没有增量积分误差，
因此暂停/单步/任意跳转都能得到完全一致的姿态。这一点很重要：它使得"单步"
和"拖动时间轴"这类交互天然正确。

## 13. 边界情况

| 情况 | 处理 |
|---|---|
| CDN 加载失败 | 显示明确的离线提示，而非黑屏（见第 4 节） |
| 窗口尺寸变化 | 监听 `resize`，更新相机 aspect 与 renderer 尺寸 |
| 高 DPI 屏幕 | `setPixelRatio(min(devicePixelRatio, 2))` |
| RPM 设为 0 | 等价于暂停，不产生除零 |
| 浏览器标签页切到后台 | `requestAnimationFrame` 自动暂停；恢复时 `getDelta` 会给出巨大值，需对 dt 做上限钳制（如 ≤ 0.1s）防止角度瞬跳 |

## 14. 验证方法

实现完成后，用以下检查确认正确性（可在控制台执行或在页面上做临时断言）：

1. **止点精度**：`pistonPosition(0)` 精确等于 `r + l`；`pistonPosition(π)` 精确等于 `l − r`。
2. **连杆定长**：随机取 1000 个 θ，验证活塞销到大头销的距离恒为 `l`（误差 < 1e-9）。
3. **相位等分**：四缸相位排序后差值为 `[180, 180, 180]`。
4. **冲程判定**：θ_cycle = 90° 判为进气、270° 为压缩、450° 为做功、630° 为排气。
5. **曲柄销符号**：θ = 90° 时曲柄销 X 坐标为负（与 7.2 的约定一致）。
6. **气门相位**：进气门升程峰值在 90°、排气门在 630°；且两者在 **200°–520°**
   区间内必须同时为 0。注意不能用 180°–540° 作区间——进气门在下止点后 20°
   才关闭、排气门在下止点前 20° 就开启，180° 与 540° 附近本就该有微小升程，
   这是真实的气门重叠，不是 bug。
7. **视觉检查**：转动到 θ = 0°，目视确认每个活塞都位于气缸最顶端，且四缸
   曲柄臂指向一致的两两成对（1&4 同相、2&3 同相）。

## 15. 风险

| 风险 | 缓解 |
|---|---|
| CDN 离线不可用 | 第 4 节的兜底提示 + 本地化说明 |
| 半透明与剖切叠加时渲染顺序错乱 | 半透明材质设 `depthWrite: false`；必要时调 `renderOrder` |
| 单文件过长影响可维护性 | 内部分节严格化；若超 1500 行则拆分为 ES 模块 |
| 连杆/活塞穿模（几何尺寸与行程不匹配） | 依据 CONFIG 反推缸套长度：`≥ stroke + 活塞高 + 余量` |
