# 3D 汽车发动机运行动画

一台运转中的直列四缸四冲程汽油发动机，浏览器中实时呈现内部活塞、连杆、
曲轴与气门的运动。半透明或剖切后可看清缸内工作过程。

## 使用

双击 `index.html` 即可。无需安装、无需构建。

> 需要联网 —— Three.js 从 CDN 加载。断网时会显示明确提示而非黑屏。

## 交互

| 操作 | 说明 |
|---|---|
| 左键拖拽 / 滚轮 / 右键拖拽 | 旋转 / 缩放 / 平移视角 |
| 转速滑块 | 0–4000 RPM |
| 暂停 / 空格 | 停止或恢复曲轴旋转 |
| 单步 +15° | 暂停状态下逐帧推进，便于观察单个冲程 |
| 剖切 | 切开缸壁露出内部 |
| 半透明 | 缸体转为玻璃质感 |
| 标签 | 开关部件名称标注 |
| 重置视角 | 依整机包围盒重新取景（窗口尺寸变化后也可用它复位） |

## 技术要点

- **运动学是解析解，不是近似**：活塞位移
  `s(θ) = r·cos θ + √(l² − r²sin²θ)`，连杆摆角
  `φ = atan2(r·sin θ, √(l² − r²sin²θ))`。
  参数取真实尺寸：缸径冲程均为 86mm，连杆 143mm，`r/l ≈ 0.30`。
- **姿态是曲轴角的纯函数**，无累积状态。因此暂停、单步、任意跳转得到的
  姿态完全一致，不会有积分漂移。
- **四缸相位** `[360°, 540°, 180°, 0°]`，点火顺序 1-3-4-2，每 180° 点火一次。
  任意时刻四缸恰好分处进气/压缩/做功/排气四个不同冲程。
- 运动学代码写在 `index.html` 的 `<script id="kinematics">` 块中，被测试脚本
  从 HTML 源码里抽取求值 —— **测试跑的就是交付的那份代码**，不存在副本漂移。

## 开发

```bash
npm test     # 运行运动学单元测试（Node 内置测试器，零依赖）
```

生产代码没有任何 npm 依赖；`package.json` 只用于跑测试。

## 离线部署

断网环境需要把 Three.js 下载到本地：

1. 取 `three.module.js` 与 `examples/jsm/` 放到本文件同目录
2. 把 `index.html` 中 importmap 的地址改为相对路径 `./three/three.module.js`
3. **必须通过 HTTP 服务器访问**（如 `python -m http.server`）——
   浏览器会以 CORS 拦截 `file://` 下的本地 ES 模块导入

第 3 条是「单文件」成为硬约束的原因：CDN 的 HTTPS 导入带
`Access-Control-Allow-Origin: *`，`file://` 页面可以直接引；而本地相对路径
模块的 origin 是 `null`，会被拦掉。
